Método

Como eu chego no resultado.

Entender o processo manual

Antes de escrever qualquer linha, acompanho como o trabalho é feito hoje. Onde o dado nasce, quem copia para onde, e qual etapa gera retrabalho.

Mapear a fonte de verdade

Se existem três planilhas com números diferentes, o problema não é automação — é definição. Só automatizo depois que existe uma base única.

Automatizar o caminho mais curto

Começo pelo fluxo que remove mais trabalho manual com menos peças. Um relatório que chega sozinho já muda a rotina — e prova o valor antes de investir em dashboard.

Entregar onde a pessoa já está

Relatório dentro do Slack, não em link que ninguém abre. A automação só funciona se ela chega no lugar onde a decisão acontece.

Monitorar e ajustar

Fluxo em produção quebra: API muda, aba é renomeada, alguém preenche errado. Trato falha como parte do sistema, com validação e registro do que não passou.

Automação boa é a que ninguém lembra que existe
até o dia em que ela para.
Vitor Hugo Santana
